قالب سایت چندصفحه‌ای فارسی

فایل‌ها:
- index.html: صفحه اصلی
- about.html: درباره ما
- services.html: خدمات
- contact.html: تماس با ما
- style.css: رنگ‌ها و ظاهر سایت
- script.js: منوی موبایل و سال جاری

ویرایش:
1) فایل‌ها را از حالت ZIP خارج کنید.
2) فایل‌های HTML را با یک ویرایشگر متن یا VS Code باز کنید.
3) عبارت «نام سایت شما» و متن‌های نمونه را تغییر دهید.
4) برای تغییر عکس پس‌زمینه، آدرس عکس داخل style.css و بخش .hero را عوض کنید.
5) برای تغییر رنگ اصلی، مقدار --accent را در ابتدای style.css تغییر دهید.

انتشار رایگان:
1) در GitHub یک repository جدید بسازید.
2) فایل‌های همین پوشه را در ریشه repository بارگذاری کنید.
3) وارد Settings > Pages شوید.
4) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5) شاخه main و پوشه /(root) را انتخاب و Save کنید.
6) پس از چند دقیقه، GitHub آدرس سایت را نمایش می‌دهد.

این قالب فقط یک شروع قابل ویرایش است؛ فرم تماس واقعی یا پنل مدیریت ندارد.
